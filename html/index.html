Hospital Discharge Manager

Simulador de gestión de altas médicas hospitalarias para demos de continuidad de negocio con Zerto. El sistema genera altas ficticias de forma continua mediante el RBG, permitiendo demostrar en tiempo real el impacto de un incidente y la recuperación con RPO de segundos.
